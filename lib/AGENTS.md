# 공통 라이브러리 지식 베이스

## 개요

빌더, 검증기, 테스트가 함께 사용하는 파이프라인 코드입니다. 변경 시 모든 생성 페이지에 영향을 줄 수 있습니다.

## 작업 위치

| 영역 | 파일 |
| --- | --- |
| 콘텐츠 레코드·관계 | `content-model.js` |
| HTML 파싱·트리 | `html-tree.js` |
| 성명서 조각 | `statement-fragment.js` |
| 공통 페이지 구성요소 | `site-components.js` |
| URL·메타데이터 | `site-utils.js` |
| 빌드 파일 도우미 | `build-utils.js` |

## 규칙

- 데이터 경계 가까이에서 검증하고 빌드 재현성을 위해 결정적인 결과를 반환합니다.
- CommonJS/Node 스타일을 유지하고 라이브러리에서 브라우저 전용 API를 피합니다.
- HTML 구조 변경은 파이프라인 테스트와 `_site/` 검증으로 확인합니다.

## 금지 사항

- 모든 호출자를 확인하지 않고 범용 도우미에 빌더 전용 동작을 추가하지 않습니다.
- 잘못된 원본 데이터를 조용히 수정하지 말고 검증 오류로 드러냅니다.
