# 테스트 지식 베이스

## 개요

콘텐츠 모델과 사이트 전체 파이프라인을 검증하는 Node 내장 회귀 테스트입니다.

## 작업 위치

| 영역 | 위치 |
| --- | --- |
| 모델·스키마 동작 | `content-model.test.js` |
| 빌드·검증 통합 | `site-pipeline.test.js` |
| 성명서 예외 사례 | `fixtures/statement/` |

## 규칙

- `npm test`로 실행하며 Node 내장 `node:test` 러너를 사용합니다.
- 구현 세부사항보다 fixture와 관찰 가능한 생성 결과에 대한 assertion을 우선합니다.
- fixture는 보호하려는 사례를 대표하면서도 최소한으로 유지합니다.

## 금지 사항

- 파이프라인을 통과시키기 위해 실패한 회귀 테스트를 삭제하거나 약화하지 않습니다.
- 현재 원본 변경으로 다시 빌드하지 않은 생성 파일을 대상으로 assertion하지 않습니다.
