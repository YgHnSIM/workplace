# 스크립트 지식 베이스

## 개요

콘텐츠 파이프라인의 명령줄 조정 계층입니다. 빌드, 정규화, 검증, 스테이징, 생성 결과 확인을 담당합니다.

## 작업 위치

| 작업 | 파일 |
| --- | --- |
| 전체 빌드 | `build-all.js` |
| 원본 정규화 | `normalize-manual-sources.js` |
| 원본·카탈로그 검증 | `validate-sources.js` |
| `_site/` 준비 | `stage-site.js` |
| 생성 결과 변경 확인 | `verify-generated.js` |

## 규칙

- `package.json`에서 호출되며 저장소 루트에서 안전하게 재실행할 수 있어야 합니다.
- 스테이징은 결정적이어야 하며 명시적으로 허용된 공개 산출물만 포함합니다.
- 검증 실패 시 0이 아닌 종료 코드를 반환해 CI가 문제 지점에서 중단되게 합니다.

## 금지 사항

- 저장소 외부 파일이나 개발자의 로컬 브라우저 상태에 의존하지 않습니다.
- 변경된 생성 결과에 맞추기 위해 검증을 약화하지 말고 원본에서 다시 생성합니다.
